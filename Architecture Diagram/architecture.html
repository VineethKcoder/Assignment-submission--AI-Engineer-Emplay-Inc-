Shared extraction state

Shared state (`ExtractionState`): plan, ingestion report, `drafts` (field -> value/sources/confidence), `evidence` (field -> passages), addendum change log, validation report, per-field validator feedback, retry round, final record, errors. Parallel branches merge through dict reducers.

All messages are Pydantic models (agents/schemas.py); LLM outputs are validated against them with one automatic repair round-trip on malformed JSON.
